# Línea de investigación — Maestría en Ciberseguridad

VenomOps es el **prototipo y caso de estudio** de un trabajo de grado sobre la seguridad de los agentes basados en LLM
que revisan y modifican infraestructura como código (IaC). La decisión y su alcance están en el
[ADR 0011](../decisiones/0011-linea-de-investigacion.md).

| Documento | Contenido |
|---|---|
| [Propuesta](propuesta.md) | Problema, pregunta de investigación, hipótesis, objetivos, alcance y aporte |
| [Modelo de amenazas](modelo-de-amenazas.md) | Activos, límites de confianza, STRIDE por componente y mapeo al OWASP Top 10 para LLM |
| [Estado del arte](estado-del-arte.md) | Análisis estático de IaC, seguridad de agentes LLM e inyección de prompt indirecta |
| [Metodología](metodologia.md) | Experimentos, benchmark, métricas, análisis estadístico, amenazas a la validez y cronograma |

> Los datos de los experimentos son **sintéticos**: ningún experimento toca infraestructura real ni usa datos de clientes
> (sección 2 de [`CLAUDE.md`](../../CLAUDE.md)).
